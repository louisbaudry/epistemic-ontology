# JSON-LD context

A JSON-LD 1.1 context for the record elements of [SPEC-001](../specs/SPEC-001-core-assertion.md).
**Version 0.1, approved by the owner on 2026-10-15.** It adds no
term: every name comes from [../core/core.ttl](../core/core.ttl) (approved 0.1)
and every value from [../vocab/](../vocab/).

| File | Content |
|---|---|
| [spec-001.jsonld](spec-001.jsonld) | The context, generated by `build.py` |
| [build.py](build.py) | Builds the context from `core/core.ttl` and `vocab/*.ttl`; `--check` tells whether the file is current |
| [examples/](examples/) | Four records in JSON-LD, one per `valid-*.ttl` file in [../shapes/tests/](../shapes/tests/) |
| [run.py](run.py) | The checks below |

## Use

Reference the context and write the record elements by their SPEC-001 names:

```json
{
  "@context": "spec-001.jsonld",
  "id": "https://example.org/a1",
  "type": "Assertion",
  "kind": "finding",
  "review": "draft"
}
```

- Controlled values are written by their notation (`"finding"`, `"likely"`,
  `"not-assessed"`). Each value is read only within its own property, so the
  same word in two schemes cannot collide.
- `asserted_at` is a `dateTime`. `valid_time` is not typed by the context,
  since SPEC-001 §8 allows a year, a year and month, or a date: write it as a
  typed value (`{"@value": "2021", "@type": "xsd:gYear"}`). An excerpt's `text`
  needs a `@language`.
- A value that is not in the scheme is not rejected by the context: it expands
  to a relative IRI, and the shapes in [../shapes/](../shapes/) then fail it
  (`sh:in`).

Run the checks with `python3 context/run.py` (needs `rdflib` and `pyshacl`).

## Provenance

- **Read:** SPEC-001 §3, §4, §5.1, §5.3, §6, §7, §8, §10, `core/core.ttl` and
  the 18 schemes in `vocab/`.
- **Checked:** the context is current with its sources; each of the six
  examples expands, under rdflib 7.6.0, to a graph identical to the matching
  Turtle test file, and conforms to the shapes; a misspelled kind value is
  caught by the shapes.
- **Not checked:** the context against the JSON-LD 1.1 specification's text, or
  with a second processor (only rdflib was run); the IRIs, since the namespace
  base is unconfirmed until GitHub Pages is enabled; the context loaded from a
  URL (it is referenced by a relative path).
- **Out of scope:** terms of SPEC-002 to SPEC-004, which have no RDF terms yet.
- Examples use invented, neutral subjects.
